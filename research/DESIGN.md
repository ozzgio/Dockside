# 1.4 design direction

Dockside is a desk instrument for a small, low-density LCD. Reading distance and clear actions matter more than adding decoration.

- Base palette: midnight #101B2A, ice #F2F7FC, steel #A6B8C9, blue #8CCDE2, amber #F4BC7A. Existing alternate palettes share the same hierarchy.
- Type: native SF Pro, medium clock digits with fixed-width numerals, semibold 20–24 pt headings, readable 18–22 pt utility content. Reserve the largest type for time and measurements.
- Layout: a quiet identity/status header; one primary content area; a single consistent command rail. Clock/Overview/Today choose content. Settings appears once, at the bottom right, with an explicit label.
- App shortcuts use the installed app's real icon and saved name. Settings, system connection details, and permission controls live on the Mac.
- Today groups schedule/reminders on the left and glanceable weather, Melbourne time, sound, and a picture dimmer on the right. Only enabled widgets appear.
- Icon: simplify the detailed clock-and-bars illustration to a recognizable miniature display with a dock base and one signal light. Use the same original vector geometry for the app and project page.

Review: a generic card grid would waste this panel's space. Keep the overview as a clock beside a structured instrument list, use restrained dividers, and give utility content only the boundaries it needs. Remove duplicate Settings actions and ambiguous icon-only navigation.
